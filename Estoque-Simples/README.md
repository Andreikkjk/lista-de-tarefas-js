# 🛸 Inventory Cockpit — Neon Glassmorphism Stock Control

A real-time inventory management system built with **vanilla HTML, CSS & JavaScript** and powered by **Supabase** as a Backend-as-a-Service. Designed as a portfolio piece with a distinctive cyberpunk/cockpit aesthetic — no frameworks, no templates, no Bootstrap.

---

## ✨ Design Philosophy

This isn't another generic dark-mode admin dashboard. Every visual decision was intentional:

- **Glassmorphism done right** — `backdrop-filter: blur(20px) saturate(180%)`, inset reflections simulating real glass edges, colored radial glow behind stat cards
- **Atmospheric lighting** — Three ambient light blobs (cyan, purple, green) with `radial-gradient` + `filter: blur(120px)` creating dynamic halos across the background
- **Film grain texture** — SVG `feTurbulence` noise overlay at low opacity, removing the flat digital feel
- **CRT terminal** — A live system log panel with scanline overlay (`repeating-linear-gradient`), macOS-style chrome bar, and a pulsing "LIVE" indicator
- **Neon typography** — `text-shadow` glow on data, gradient text on headings (`background-clip: text`), and a `Space Mono` + `Syne` font pairing

## 📦 Features

- **Full CRUD** — Create, Read, Update products directly on Supabase
- **Relational data** — Products reference a `categorias` table via Foreign Key; the Supabase client performs the JOIN automatically
- **Dynamic category management** — Create new categories on the fly; dropdowns populate from the database
- **Smart filters** — Filter by category and price range (min/max) with instant re-render
- **Low stock alerts** — Configurable threshold with pulsing red neon indicator
- **Live system terminal** — Every action (fetch, insert, update, filter, error) is logged in real time to a styled terminal panel
- **Animated stat counters** — Numbers count up/down smoothly via `requestAnimationFrame`
- **Micro-interactions** — Hover glow on buttons, row highlight with cyan left-border, modal entrance animation

## 🗄️ Database Schema

```sql
-- Categories table
CREATE TABLE categorias (
    id    BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    nome  TEXT NOT NULL
);

-- Products table (FK → categorias)
CREATE TABLE "estoque produtos" (
    id            BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    nome          TEXT NOT NULL,
    categoria_id  BIGINT REFERENCES categorias(id),
    quantidade    INTEGER NOT NULL,
    preco         DOUBLE PRECISION NOT NULL,
    created_at    TIMESTAMPTZ DEFAULT NOW()
);
```

## 🚀 Getting Started

1. **Clone the repo**
   ```bash
   git clone https://github.com/YOUR_USERNAME/inventory-cockpit.git
   cd inventory-cockpit
   ```

2. **Set up Supabase**
   - Create a free project at [supabase.com](https://supabase.com)
   - Run the SQL schema above in the **SQL Editor**
   - Copy your **Project URL** and **Publishable Key** from **Settings → API Keys**

3. **Configure credentials**
   Open `app.js` and replace the placeholder values at the top:
   ```javascript
   const supabaseUrl = "YOUR_SUPABASE_URL";
   const supabaseKey = "YOUR_PUBLISHABLE_KEY";
   ```

4. **Run locally**
   Open `index.html` with any local server (e.g. VS Code Live Server extension) or simply open the file in your browser.
